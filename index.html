Prototype source

This GitHub Pages build derives its NRL relationship graph in your browser from the public uselessnrlstats player-match dataset. The League Links production database retains its own identity resolution, source provenance and lower-grade career backfill layers.

Counting rule: two players count as teammates only when both appear for the same team in the same match. Missing evidence is not treated as zero.
