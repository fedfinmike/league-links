Counting rule

A teammate game is created only when two players appear for the same team in the same match. Club membership, squad membership and team-list co-selection are not silently converted into games together.

  1. Confirmed same-match appearances
  2. Exact numeric teammate records
  3. Official team-list co-selection
  4. Squad membership
  5. Season-level club overlap

This GitHub Pages prototype derives its NRL spine from the public uselessnrlstats dataset. A separate licensing/terms review is required before treating any third-party dataset as a commercial production source.
