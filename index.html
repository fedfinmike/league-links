Coverage across the game.

League Links is building one connected record from under-17 pathways through state cups, NRL, Origin and international football, using the strongest records available for each season.

How a player link is counted

Two players are linked only when both are recorded for the same team in the same match. Being on the same squad list does not count as a game together.

How coverage grows

Teams are mapped first, season player records are added next, and teammate links are only created from confirmed match appearances. The database expands automatically as reliable historical records are added.
