# League Links

League Links is an interactive rugby league player-connections prototype.

The prototype lets you open a player ledger, rank confirmed teammates by games played together, click any teammate to open that player's own ledger, open Shared Playing History, find connection paths between players, and explore club-season rosters.

The current public prototype uses the League Links exact NRL evidence spine covering 2008–2026. The 2026 season is treated as a current-season partial snapshot.

## Live prototype

https://fedfinmike.github.io/league-links/

## Evidence rule

A confirmed teammate relationship requires both players to appear for the same team in the same match. Squad membership, team-list-only selection, and same-season club overlap are not counted as games together.
